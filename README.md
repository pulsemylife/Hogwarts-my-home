# Hogwarts — PWA

Русскоязычная веб-версия Hogwarts Dark Messenger, подготовленная для GitHub Pages и PWA Builder.

## Функции
- Личные чаты со всеми учениками и 8 преподавателями.
- Сценарные ответы персонажей с индивидуальной манерой общения.
- Групповые чаты и создание собственных групп.
- Сюжетные поручения преподавателей с выбором вариантов.
- Система отношений: доверие, уважение, соперничество.
- Профиль ученицы, школьные события и журнал заданий.
- Локальное сохранение данных в браузере (`localStorage`).
- PWA-манифест, Service Worker, офлайн-кэш и иконки установки.

## Публикация на GitHub Pages
1. Создайте отдельный репозиторий, например `hogwarts-pwa`.
2. Загрузите **всё содержимое этой папки** в корень репозитория: `index.html`, `manifest.json`, `sw.js`, `app.js`, `styles.css`, папку `icons`.
3. В GitHub откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, затем Save.
5. Дождитесь публикации сайта. Откройте адрес GitHub Pages по HTTPS.
6. В PWA Builder вставьте опубликованный HTTPS-адрес и запустите проверку.

## Важно
- Нужен именно опубликованный HTTPS-сайт; локальный `file://` адрес и ссылка на репозиторий не подойдут.
- PWA Builder использует `manifest.json`. Нативный `AndroidManifest.xml` из Kotlin-проекта для этого не подходит.
- Диалоги пока сценарные, не подключён настоящий ИИ.
- Данные хранятся в браузере на конкретном устройстве и не синхронизируются между устройствами.
- Google Fonts подключается из сети; при офлайн-работе интерфейс использует системный шрифт.
- Исходный Kotlin Android-проект не изменён.
