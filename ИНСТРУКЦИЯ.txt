ИСПРАВЛЕНИЕ КЭША PWA BUILDER

По присланным скриншотам текущий manifest.json уже указывает на корневые иконки,
но PWA Builder продолжает показывать старый путь /icons/icon-192.png.
Это означает, что он использует старый результат проверки или закэшированный манифест.

Сделай так:
1. В GitHub открой index.html и замени его файлом из этого архива.
   В нём ссылка на манифест меняется на ./manifest-v2.json.
2. Добавь в корень репозитория новый файл manifest-v2.json из архива.
3. Замени sw.js файлом из архива (новая версия кэша v3).
4. Старый manifest.json можно оставить, ничего не удаляй.
5. Нажми Commit changes и подожди, пока GitHub Pages обновится.
6. Открой в браузере:
   https://pulsemylife.github.io/Hogwarts-my-home/manifest-v2.json
   Убедись, что в поле src иконок адреса начинаются с
   https://pulsemylife.github.io/Hogwarts-my-home/icon- (без /icons/).
7. В PWA Builder начни НОВУЮ проверку, вставив:
   https://pulsemylife.github.io/Hogwarts-my-home/?scan=2
   Не открывай старый сохранённый результат проверки.

Файлы иконок не перемещай. Они остаются в корне репозитория рядом с index.html.
Функциональность приложения не меняется.
